# 0015. Соблюдение Conventional Commits

## Статус
Принято

## Контекст
Соло-разработка. Нужна читаемая история для себя и нанимателя.

## Решение
- Conventional Commits (`feat`, `fix`, `docs`, `test`, `refactor`, `chore`).
- Основная ветка — `main`.
- Feature-ветки для крупных фич (>1 дня).
- Merge с `--no-ff` (сохраняет историю).
- Squash — только для мусорных веток.
- Удалять ветки после merge.
- Tag'и — на релизах.
- Версионирование: `0.x.y` до MVP, `1.0.0` на MVP.

## Последствия
**Проще:**
- Читаемая история.
- Автоматический CHANGELOG.
- Сигнал дисциплины для нанимателя.

**Сложнее:**
- Дисциплина в сообщениях.
- Нельзя «wip» коммиты.
