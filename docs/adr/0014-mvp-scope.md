# 0014. Область MVP

## Статус
Принято

## Контекст
Проект большой. В декрете — 1 час в день.
Нужен показываемый артефакт быстро.

## Решение
MVP:
- Клас: волшебник.
- Уровни: 1-5.
- 20 заклинаний.
- Use cases: build, level-up, cast, short rest, long rest.
- Play: справка по actions + каст.
- Combat — потом.

Отложено:
- Мультикласс (в модели — есть, в логике — нет).
- Concentration, Conditions, Death Saves.
- Полный справочник.

## Последствия
**Проще:**
Быстрый результат.
Архитектура заложена под расширение.
Публикация через 6 месяцев.

**Сложнее:**
Часть логики — заглушки.
Расширение — отдельные итерации.
