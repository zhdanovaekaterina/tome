# 0004. Learn и Prepare — разные оси

## Статус
Принято

## Контекст
В D&D три модели кастеров:
- Known (бард, сорка) — фиксированный список.
- Spellbook (волшебник) — книга + подготовка из книги.
- Prepared (клирик, друид) — подготовка из полного списка класса.

Первый подход (одна сущность «список заклинаний») не выражал разницу.
Застревание на «learn vs prepare без дублирования».

## Решение
- `CharacterSpell` с `List[SpellSourceRecord]` — каждое заклинание с источниками.
- `SpellSourceRecord` — `(source, status, source_key, added_at_level)`.
- `SpellStrategyDefinition` — абстракция над «как учит / как готовит».
- `LearnSource` / `PrepareSource` — enum, откуда брать кандидатов.

## Последствия
**Проще:**
- Все три модели выражаются одной структурой.
- Одно заклинание может быть из класса + подкласса + расы.

**Сложнее:**
- UI должен показывать источники.
- `is_castable` — проверка по статусам + ритуал.
