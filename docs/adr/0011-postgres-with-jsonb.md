# 0011. Postgres с использованием JSONB

## Статус
Принято

## Контекст
Фичи полиморфны — разные поля у разных типов.
Table-per-type — 10+ таблиц. NoSQL — вторая БД.
Postgres JSONB — гибрид.

## Решение
- Справочники — реляционные таблицы.
- `features.payload: JSONB` — поля фичи.
- `type` — в отдельной колонке.
- Domain резолвит `payload` → класс по `type`.

## Последствия
**Проще:**
- Одна БД.
- Транзакции для персонажа.
- JSONB даёт гибкость.

**Сложнее:**
- JSONB не типизирован в БД.
- Валидация — в Python.
