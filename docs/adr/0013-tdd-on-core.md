# 0013. Разработка ядра через TDD

## Статус
Принято

## Контекст
Проект для портфолио. Цель — middle+.
TDD — дисциплина + доказательство компетенций.

## Решение
- Shared → Reference → Domain → API → Infra.
- Тесты на каждом слое до следующего.
- Фейки репозиториев в памяти.
- Интеграционные тесты — testcontainers (потом).

## Последствия
**Проще:**
- Ядро тестируется без БД и API.
- Ошибки ловятся рано.
- Рефакторинг безопасен.

**Сложнее:**
- Медленнее написание.
- Нужны фейки.
