# 0006. Фичи как контейнеры

## Статус
Принято

## Контекст
Класс, подкласс, раса, подраса, предыстория — все дают фичи.
Изначально подкласс был фичей — но подкласс растянут на уровни
и является источником фич, не фичей.

## Решение
- **Контейнеры** — `ClassData`, `SubclassData`, `RaceData`, `SubraceData`, `BackgroundData`.
- Каждый контейнер имеет `features_by_level: dict[ClassLevel, list[FeatureDefinition]]`.
- **Общий интерфейс** `FeatureContainer` — Protocol с `id`, `name`, `get_by_level`.
- Domain собирает фичи из всех контейнеров.

## Последствия
**Проще:**
- Симметрия: класс и раса — одинаковые контейнеры.
- Domain собирает фичи универсально.
- Новый контейнер (Feat, Item) — новый класс.

**Сложнее:**
- `FeatureContainer` — минимальный, только общее.
- Специфика контейнеров — в отдельных интерфейсах.
